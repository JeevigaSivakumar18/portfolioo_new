Jeeviga Sivakumar — Portfolio 🚀

A modern, brutalist-themed personal portfolio showcasing my education, technical expertise, selected works, and core interests as an aspiring Computer Science Engineer.

🛠️ Tech Stack

- Frontend: HTML5, CSS3, JavaScript (Vanilla)
- Styling & Design: Custom CSS Grid & Flexbox, Font Awesome, Custom Brutalist UI Theme
- Tools & Deployment: Git & GitHub, Vercel

✨ Features

- Interactive Introduction: Responsive hero section with dynamic hover effects and custom portrait layout.
- Technical Expertise: Grid-based cards showcasing programming languages, web technologies, databases, and development tools.
- Areas of Interest: Quick overview of core domains like UI/UX Design, DBMS, and AIML.
- Selected Projects: Detailed showcases for full-stack and mobile applications (StudyBuddy, Bus Alarm, Campus Navigation) with live GitHub links and responsive previews.
- Resume & Contact: Direct resume download and easy access to professional links (GitHub, LinkedIn, LeetCode, Email).

🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/JeevigaSivakumar18/portolioo_new.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portolioo_new
   ```

3. Open the project:
   Simply open index.html in your favorite web browser, or run it using a local development server like Live Server in Visual Studio Code.
